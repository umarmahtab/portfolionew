# Umar Mahtab Portfolio

A modern, single-page portfolio website for Umar Mahtab. The site is built as a self-contained HTML page with a premium glassmorphism look, theme switching, animated sections, and contact links for sharing work or connecting with recruiters.

## What’s Inside

The portfolio highlights the main parts of Umar’s profile:

- Hero section with title, short intro, and call-to-action buttons
- About section describing background and interests
- Skills section covering programming, web development, backend, tools, AI, design, and soft skills
- Education and experience sections
- Projects showcase
- Certifications and languages sections
- Contact form plus direct links to email, LinkedIn, and GitHub

## Features

- Responsive single-page layout
- Theme switcher with multiple visual styles
- Smooth scroll and animated reveal effects
- Typing text animation in the hero section
- Glass-style cards, ambient orbs, and polished UI details
- Mobile-friendly navigation menu
- Contact form with a send-state interaction
- Social and email links for quick outreach

## Project Files

- `Portfoliov4.html` - Main portfolio page
- `README.md` - Project overview and usage notes
- `images/` - Image assets used in the portfolio
- `images/projects/` - Project preview images

## How To Run

This is a static HTML project, so you can open `Portfoliov4.html` directly in any browser.

For a smoother editing experience, open the folder in VS Code and launch the page with Live Server or another local preview tool.

## Customization Guide

You can personalize the portfolio by editing the HTML file:

- Update the hero text, about content, and contact details
- Replace project cards, links, and preview images with your own work
- Edit the skills, education, experience, certifications, and languages sections
- Change the theme colors and effects in the `<style>` block
- Adjust interactive behavior in the `<script>` block

## Tech Stack

- HTML5
- CSS3
- JavaScript
- Google Fonts

## Notes

- The project is intentionally kept in one HTML file for easy sharing and deployment.
- If you add new assets, keep them inside the `images/` folder and update the corresponding paths in the HTML.
- If you rename the main HTML file, update this README so the run instructions stay accurate.
